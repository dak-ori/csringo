# 졸업논문 발표 PPT 내용 수정 + 발표 대본 작성

## 개요

- 대상 파일: `docs/csquest_presentation_v2.pptx` (`docs/csquest_presentation.pptx`를 복사한 작업용 파일, 원본은 보존)
- 기준 문서: `paper/논문_최종본.pdf` (최종 논문 7페이지) — 이 문서에 적힌 내용만을 사실 근거로 사용한다. 코드베이스나 실제 화면 구현은 참고하지 않는다.
- 발표 시간: 질의응답 포함 5~10분, 실발표 약 5~6분 목표
- 슬라이드 수/순서/디자인: 기존 13장 구성 그대로 유지, 변경 없음

## 작업 1 — 논문 기준 사실 오류 수정 (3건)

기존 13장 PPT를 논문 전문과 줄 단위로 대조해 찾은 불일치:

1. **슬라이드 1 (표지)**: "지도교수: 박수헌" → "지도교수: 박수현" (논문 전체에 일관되게 "박수현"으로 표기됨, 단순 오타)
2. **슬라이드 8 (LLM-as-a-Judge 검증 모듈)**: 검증 실패 원인 귀속이 논문 4.2절과 다르고, 같은 PPT의 슬라이드 10과도 불일치함.
   - 논문 원문: "검증 실패의 주요 원인은 난이도 적합성 불일치(약 18%)와 정답 표현의 모호성(약 12%)이었다."
   - 현재 슬라이드 8: 18%를 "정답 정확성"(오답 생성) 항목에, 12%를 "명확성" 항목에 붙여놓음 — "난이도 적합성" 항목에는 수치 없음
   - 수정 후: 18%는 "난이도 적합성" 항목으로, 12%는 "정답 표현의 모호성"(명확성과 연결되는 항목)으로 옮긴다. "정답 정확성" 항목에는 논문에 없는 수치를 임의로 붙이지 않는다.
3. **슬라이드 11 (AI 복습 큐 + 게이미피케이션)**: 논문 3.7절에 없는 구체적 수치/명칭이 들어가 있음 — "레벨업 임계치 0→100→300→600→1000 XP", "하트 5개 자동회복", "실버·골드 리그" 등.
   - 논문 원문 수준: "정답 및 레슨 완료 시 XP가 지급되고, 오답 시 하트가 소모되어 과도한 반복 학습을 억제한다. 스트릭과 리그는 학습 동기를 유지하기 위한 보조 메커니즘으로 활용된다."
   - 수정 후: 위 문장 수준으로 일반화하고, 논문에 없는 구체적 숫자·티어 명칭은 제거한다.

## 작업 2 — 발표자 노트에 대본 작성 (13장 전체)

- 위치: 각 슬라이드의 PowerPoint 발표자 노트(notes slide) — 별도 파일 아님
- 어투: 심사위원 앞 발표체 ("~습니다/입니다")
- 분량: 슬라이드별로 시간 배분, 합계 약 5~6분
  - 표지/목차: 15초씩
  - 연구배경, 차별점, 시스템개요, 콘텐츠구조: 30~35초씩
  - 핵심 기여 파이프라인(7), 검증모듈(8), 재생성모듈(9), 평가결과(10): 30~35초씩
  - 복습큐+게이미피케이션(11): 30초
  - 데모(12): 20초
  - 결론(13): 30초
- 각 노트 끝에 "(약 XX초)" 타이밍 가이드 표기
- 대본 내용은 해당 슬라이드에 실제로 적힌 텍스트(수정된 내용 포함)를 풀어서 말하는 것이며, 슬라이드에 없는 새로운 주장을 추가하지 않는다

## 구현 방식

- ppt-maker conda 환경의 python-pptx로 직접 `docs/csquest_presentation_v2.pptx`의 텍스트 런(run)을 수정하고, 각 슬라이드에 `notes_slide.notes_text_frame.text`로 발표자 노트를 채운다
- 이미지(슬라이드 12 스크린샷 3장)는 그대로 유지, 손대지 않음
- 작업 후 슬라이드 8/10 수치 일치 여부, 슬라이드 1 오타 수정 여부를 텍스트 추출로 재검증한다
